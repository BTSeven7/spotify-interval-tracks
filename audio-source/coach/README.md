# Coach voice clips

Original recordings, kept unprocessed. The app uses the processed copies in
`public/audio/coach/`, which were made from these by:

- trimming silence at the start (20 ms kept) and end (80 ms kept)
- matching volume to about -14 LUFS, with a limiter at -1 dB
- encoding as mono, 44.1 kHz, 96 kbps MP3

`public/audio/coach/countdown-beep.mp3` is generated (880 Hz, 180 ms) and has
no source recording.
